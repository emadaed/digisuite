## 🚀 Featured Projects

### GrowEasy — AI-Powered ERP for SMEs *(Flagship)*
Full-stack SaaS ERP platform built for retailers, wholesalers, and freelancers.
**Stack**: Python, Flask, PostgreSQL, Redis, Celery, Docker, Sentry, Multi-Agent architecture.
Live demo available.

### Ahmad-AI — Islamic Knowledge Assistant *(Live · Public Demo)*
A fully local, offline, multilingual AI assistant serving 6,236 Quran verses and 50,762 Hadith texts from nine canonical collections. Combines exact citation lookup, semantic search, and hybrid multilingual query expansion (English, Arabic, Urdu).
**Stack**: Python, LangGraph, Ollama, ChromaDB, Sentence-Transformers, Streamlit, Cloudflare Tunnel.
→ [Read the Engineering Log 02](https://emadaed.github.io/digisuite/engineering-log-2.html)

### Ahmad-AI — Guardrailed ERP Agent *(Live · Private)*
Local, tool-calling AI agent (LangGraph + Ollama) with live, read-only access to a production Postgres SCM/ERP database. Engineered deterministic fallback guardrails against hallucinated data and unverified citations, bounded execution with a hard iteration ceiling, and scoped retry logic distinguishing transient from permanent failures.
Verified by a **22-test regression suite** and an **end-to-end harness** separating deterministic guardrail checks from LLM-reasoning review.
→ [Read the Engineering Log 01](https://emadaed.github.io/digisuite/engineering-log.html)

### Learn With Misham — Scalable CRM & LMS *(Live)*
Cloud-based education management platform managing student admissions, progress tracking (Anki-style), and automated reports.
Successfully used by multiple Quran academies and adaptable to other domains.

### Serverless Enterprise Warehouse Management System *(Open Source)*
Lightweight end-to-end fulfillment system built with Google Sheets + Apps Script.
Automates invoicing, packing slips, shipping labels, and records — a practical alternative to expensive commercial WMS.
